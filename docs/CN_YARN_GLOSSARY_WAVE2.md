## 方針

第2次調査では、既存33語を再説明するのではなく、中国のニット・毛衫・花式纱线市場で使われる未登録語を探索した。

KIMIの調査結果はそのまま全件登録せず、次の基準で整理した。

- 構造・工程の定義が比較的明確
- 既存辞典語と重複しない
- Knit Compassで検索価値がある
- 市場呼称だけで構造を断定しない
- A/B/C評価に矛盾がある語は保留する
- 既存の技術標準と似た語でも、意味が広い場合は安易にaliasへ固定しない

## AB纱の訂正 — Siroの別名ではなく「効果語」

当初のKIMI整理では `AB纱＝赛络纺／Siro` としていたが、これは狭すぎる。

中国の糸メーカー説明では、AB風格は次の複数方法で実現できる。

- 同じ原料でも色違い単糸を**合股（合撚）**する
- 異なる原料の単糸を**合股（合撚）**する
- 色違いまたは異原料の2本粗紗を使って**赛络纺／Siro**で作る
- 并条・粗纱など前紡段階からA/Bを配合する

したがってKCでは、`AB纱／AB纱效果`を**単一構造名ではなく「A/B差が視覚化された色・原料効果」**として登録する。

### KCの判定ルール

- `AB纱＝Siro` と自動判定しない
- `AB纱＝合撚` とも自動判定しない
- まず **AB效果** として保持する
- 実構造は別途、`合撚` / `Siro` / `前紡A/B配合` / その他で確認する
- A/Bが「色差」なのか「原料差」なのか、その両方なのかを確認する

Siro／赛络纺は引き続き独立した技術標準として扱い、中国語別名は `赛络纺／赛络纱／并捻纺` を中心にする。AB表記だけをSiro aliasにはしない。

## 運用ルール

- `段彩` と `段染` を同義扱いしない。
- `色纺` からRing／MVS／VORTEX等の最終紡績方式を推定しない。
- `AB纱` からSiro／合撚などの構造を推定しない。
- `金银丝` と `珠片纱` を同じ「ラメ」だけでまとめない。
- `植绒` と `拉毛／磨毛` を同じ起毛加工として扱わない。
- 中国市場語が複数の作り方で同じ外観効果を出す場合、構造名ではなく効果語として扱う。
- 保留語は確度を上げるまで正式辞典へ昇格しない。
