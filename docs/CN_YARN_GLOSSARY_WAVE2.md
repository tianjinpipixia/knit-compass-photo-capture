## 方針

第2次調査では、既存33語を再説明するのではなく、中国のニット・毛衫・花式纱线市場で使われる未登録語を探索した。

KIMIの調査結果はそのまま全件登録せず、次の基準で整理した。

- 構造・工程の定義が比較的明確
- 既存辞典語と重複しない
- Knit Compassで検索価値がある
- 市場呼称だけで構造を断定しない
- A/B/C評価に矛盾がある語は保留する
- 既存の技術標準（Siro等）に統合できる語は別名として扱う

## 分類軸の追加

既存の4層を維持しつつ、色・特殊材料を無理に「構造」へ押し込まないため横断軸を追加する。

## 既存語へ統合する別名

### AB纱 → Siro／赛络纺

`AB纱`、`A，B纱`、`并捻纺`は独立した新構造として登録せず、既存のSiro／赛络纺の中国語別名・検索語へ追加する。

KCでは次の分類を維持する。

- 最終紡績方式: Ring系
- 糸構造: Siro
- Sirofil／Core-spunとは別

## 運用ルール

- `段彩` と `段染` を同義扱いしない。
- `色纺` からRing／MVS／VORTEX等の最終紡績方式を推定しない。
- `金银丝` と `珠片纱` を同じ「ラメ」だけでまとめない。
- `植绒` と `拉毛／磨毛` を同じ起毛加工として扱わない。
- 中国市場語が既存の標準技術名の別名なら、独立項目を増やさずaliasへ統合する。
- 保留語は確度を上げるまで正式辞典へ昇格しない。
