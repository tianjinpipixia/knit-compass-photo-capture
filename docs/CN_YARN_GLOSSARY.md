# 中国糸名・素材名辞典

辞典ID: `KC-CN-YARN-001`  
対象: Knit Compass 商品調査・Human Review  
基礎データ: `brand-intelligence/data/cn-yarn-glossary.json`  
第2波データ: `brand-intelligence/data/cn-yarn-glossary-wave2.json`

## 目的

中国の展示会、糸BOOK、WeChat、メーカー資料で使われる糸名を、日本のニット実務で扱える構造・加工・市場呼称へ分解して検索できるようにする。

最重要方針は **「中国語の商品名・市場名＝糸構造」ではない** こと。

## 4層＋2横断軸

基本の4層を維持し、色・特殊材料を無理に構造へ押し込まないため2つの横断軸を追加する。

1. **基本構造** — 短繊維紡績糸、長繊維複合糸、合撚、エアー交絡など
2. **ファンシー構造** — 花捻、圈圈、结子、大肚、竹节、羽毛、睫毛、带子、雪尼尔、喷毛など
3. **後加工** — 拉毛、磨毛、刷毛など
4. **市場呼称・外観名** — 小马海、皮毛纱、仿貂绒、仿马海、冰麻など
5. **染色・色効果** — 色纺、彩点、段彩、段染、AB效果など
6. **特殊材料・複合** — 金银丝、珠片、植绒など

前紡工程（カード／コーマ等）と最終紡績方式（リング／コンパクト／MVS・VORTEX／エアジェット／OE・ローター）も別項目のまま維持する。

## 表示・検索項目

- 中国語市場名
- 簡体字別名
- 日本語標準名
- **代表的な糸タイプ（例）**
- よく使う実繊維
- 分類
- 判定注意
- 検索キーワード
- 展示会・Supplier確認ポイント

`糸例`、`代表的な実際の糸`は標準ラベルとして使用しない。

## 最重要ルール

### 市場名は原料証明ではない

`仿〇〇`、`小马海`、`皮毛纱`、`冰麻`、`丝麻`などは、外観・風合い・用途・販売カテゴリーを示す場合がある。天然ミンク、Rabbit/Angora、Cashmere、Mohair、Fox、Alpaca、Linen、Silkなどの含有は、混率表示、規格書、Supplier確認で確定する。

### 後加工名から元糸構造を推定しない

`拉毛纱`、`磨毛纱`、`刷毛纱`は後加工・毛羽効果を示す名称として扱う。`拉毛纱＝花捻`、`拉毛纱＝コアスパン`などの自動推定は禁止する。

### 色・外観効果から紡績方式を推定しない

`色纺`、`段彩`、`段染`、`AB纱效果`などは、色の出し方・外観効果を示す軸として扱う。これらの名称だけからRing／Siro／MVS／VORTEX／合撚等を確定しない。

### Supplier固有用法を一般定義へ昇格しない

同じ中国語名でもメーカーごとに定義が異なる場合がある。メーカー本人確認済みの工艺はSupplier固有情報として保存し、中国市場一般の辞典定義とは分離する。

## KIMI中国語調査の反映（2026-08-19）

KIMIの中国語横断調査を第2波の入力として使用した。ただし、強い断定はそのまま採用せず、メーカー資料・規格・既存Supplier確認との整合を確認して反映した。

### 双曲纱／曲珠纱

主流の`双曲／曲珠`は、粘胶長糸＋锦纶長糸等をネットワーク／エアー交絡し、撚糸する長繊維複合加工糸として扱う。一般辞典では **花捻（芯＋飾＋固）のファンシー撚糸とは分離**する。

一方で、Supplierが別の花式工艺を`双曲`と呼ぶ事例は、Supplier固有用法として保存し、一般定義を書き換えない。

### 喷毛纱

`喷毛纱`を独立項目として追加。FZ/T 22016-2019で業界標準が存在し、外層の空心网状带子と、内部へ気流で吹き込まれた松散繊維からなる内外二重構造として扱う。

### 羽毛纱／睫毛纱

中国メーカーでは同系列・同義に近く扱われる例が多い。辞典では相互参照させるが、全Supplierで完全同義とは固定せず、毛足形状・ピッチ・製法を確認する。

### 色纺拉毛纱

`色纺`は、繊維を先に染色・混色してから紡績する考え方で、**花捻構造を意味しない**。

ただし、`色纺拉毛纱`という商品名だけから元糸を単純な短繊維単糸に固定することもしない。元糸構造・最終紡績方式・拉毛工程を別々に確認する。

### AB纱／AB纱效果

`AB纱`は**Siro／赛络纺の別名に固定しない**。

中国市場ではAB効果を複数方法で作る。

- 色の違う単糸を合撚する `AB合股纱`
- 異原料の単糸を合撚する
- 2本の粗紗を使ってSiro／赛络纺で作る
- 并条・粗纱等の前紡段階からA/Bを配合する

したがってKCでは、`AB纱／AB纱效果`を **⑤ 染色・色効果：A/B差の視覚効果** として登録し、実構造を別途確認する。

## 正式糸マスターとの関係

辞典画面は同一オリジンの `localStorage kc_independent_practical_v0_4` に保存された `yarns` を読取専用で参照する。

中国語市場名、別名、日本語名、検索キーワードと、現在の糸マスターの糸名・品番・Supplier・構造・混率・Gauge・機能・メモを照合し、一致候補を表示する。

辞典から糸マスターを自動更新しない。辞典の一致は候補表示であり、Human Reviewの確認状態を変更しない。

## 展示会・Supplier確認での使い方

1. 中国語名を検索する。
2. 4層＋2横断軸のどこに属する語か確認する。
3. 市場呼称・後加工・色効果だけなら、基本構造を未確認のまま残す。
4. 芯糸、飾り糸、固糸、合撚、エアー交絡、钩编、喷毛、起毛前元糸、最終紡績方式をSupplierへ確認する。
5. 混率と天然繊維の有無を現物・規格書で確認する。
6. Supplier固有定義は一般辞典ではなく個別糸レコード側へ保存する。
