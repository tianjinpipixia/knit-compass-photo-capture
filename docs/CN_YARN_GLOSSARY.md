# 中国語糸名 ↔ 日本語標準名 辞書

辞書ID: `KC-CN-YARN-001`  
対象: Knit Compass 商品調査・Human Review
データ正本: `brand-intelligence/data/cn-yarn-glossary.json`

## 目的

中国の展示会、糸BOOK、WeChatで頻出する市場名を、日本のニット実務で想像しやすい日本語名と糸タイプへ橋渡しします。

表示項目は次を標準とします。

- 中国語市場名
- 簡体字別名
- 日本語標準名
- **代表的な糸タイプ（例）**
- よく使う実繊維
- 分類
- 天然対象繊維の確認注意
- 検索キーワード
- 展示会確認ポイント

`糸例`、`代表的な実際の糸`は標準ラベルとして使用しません。

## 最重要ルール

`仿〇〇`、`冰麻`、`丝麻`などの市場名は、原料混率そのものを意味しません。見た目、風合い、毛足、ドライ感、商品カテゴリーを示す販売上の呼称として扱います。

天然ミンク、Rabbit/Angora、Cashmere、Mohair、Fox、Alpaca、Linen、Silkなどの含有は、必ず混率表示、規格書、Supplier確認で確定します。辞書の名称だけで天然繊維を含むと判定しません。

## 正式糸マスターとの関係

辞書画面は同一オリジンの `localStorage kc_independent_practical_v0_4` に保存された `yarns` を**読取専用**で参照します。

中国語市場名、別名、日本語名、検索キーワードと、現在の糸マスターの糸名・品番・Supplier・構造・混率・Gauge・機能・メモを照合し、一致候補の件数と代表レコードを表示します。

辞書から糸マスターを自動更新しません。辞書の一致は候補表示であり、Human Reviewの確認状態を変更しません。

## 展示会での使い方

1. 中国語名を検索する。
2. 日本語標準名と「代表的な糸タイプ（例）」で外観・構造を想像する。
3. よく使う実繊維を参考にしつつ、混率を現物で確認する。
4. 芯糸、毛足、起毛方法、強撚、カバリング、ゲージなど「展示会確認ポイント」をSupplierへ確認する。
5. 必要なら正式糸マスター一致候補を確認する。

## 追加ルール

今後の追加語も、名称の直訳だけでなく「日本で何の糸タイプとして想像すべきか」を優先して登録します。Supplier固有商品名は市場一般名と分離し、事実確認できない原料・構造を確定値として辞書へ入れません。
